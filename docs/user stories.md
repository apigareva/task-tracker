# User Stories — Task Tracker Application

## Общий контекст

Система предназначена для создания и отслеживания задач в команде, с возможностью объединения их в проекты и формирования команды проекта.

## Роль: Администратор (Admin)

### Управление пользователями

- **US-ADMIN-01**: Создавать учетные записи пользователей.
- **US-ADMIN-02**: Блокировать и разблокировать пользователя.

### Аудит и контроль

- **US-ADMIN-03**: Просматривать лог действий пользователей по задаче (изменение статуса задачи, назначение исполнителя, добавление комментариев, файлов и т.д.)

## Роль: Пользователь (User)

### Дашборд команд

- **US-USER-01**: Просматривать все команды

### Дашборд проектов

- **US-USER-02**: Просматривать все проекты

### Дашборд задач

- **US-USER-03**: Просматривать все задачи
- **US-USER-04**: Искать задачу по названию
- **US-USER-05**: Фильтровать задачи по приоритету
- **US-USER-06**: Фильтровать задачи по исполнителю
- **US-USER-07**: Фильтровать задачи по статусу
- **US-USER-08**: Фильтровать задачи по дате

### Карточка задачи

- **US-USER-09**: Создавать новую задачу с полями: заголовок, описание, приоритет и срок выполнения.
- **US-USER-10**: Редактирвоать задачу
- **US-USER-11**: Менять исполнителя по задаче
- **US-USER-12**: Добавлять задачу к проекту
- **US-USER-13**: Добавлять комментарий к задаче
- **US-USER-14**: Удалять свой комментарий к задаче
- **US-USER-15**: Добавлять файл к задаче
- **US-USER-16**: Удалять свой файл к задаче
- **US-USER-17**: Добавлять тег к задаче

### Уведомления

- **US-USER-18**: Просматривать все уведомления по назначенным задачам
- **US-USER-19**: Переходить из уведомления в карточку задачи
