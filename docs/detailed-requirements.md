# Детальное ТЗ — Task Tracker Application

## 1. Назначение системы
 
Task Tracker Application - система для организации и отслеживания задач в команде.

- создавать проекты
- создавать команды для проектов
- редактировать команду для проекта
- создавать задачи внутри проекта
- назначать задачи на пользователя
- менять статус задач («К выполнению», «В работе», «Завершено»)
- оставлять комментарии к задачам
- прикреплять файлы к задачам
- отслеживать все изменения по задаче
- фильтрация задач
- поиск задач по названию
- система уведомлений для пользователей при назначении на него задач
- возможность категоризации задач по тегам
